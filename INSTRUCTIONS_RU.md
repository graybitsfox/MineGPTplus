# Инструкция по запуску проекта "Цивилизация Ботов"

Здравствуйте!

Этот проект содержит полностью реализованную симуляцию "цивилизации" ботов для Minecraft. Боты могут самостоятельно выбирать лидера (Старосту), который, в свою очередь, ставит цели для деревни (например, "добыть 64 блока дерева" или "скрафтить 4 печки"), а боты-рабочие координируются для их выполнения.

Для запуска симуляции необходимо подключить ботов к **вашему собственному серверу Minecraft**.

## Шаги для запуска

### 1. Установка зависимостей

Если вы еще не сделали этого, откройте терминал в папке проекта и выполните команду:
```bash
npm install
```

### 2. Настройка подключения к вашему серверу

Вам нужно создать файл с именем `.env` в корневой папке проекта. Этот файл будет содержать данные для подключения к вашему серверу.

Скопируйте в него приведенный ниже шаблон и **внимательно** заполните его в соответствии с настройками вашего сервера.

```dotenv
# === ОБЯЗАТЕЛЬНЫЕ ПАРАМЕТРЫ ===

# IP-адрес или доменное имя вашего сервера
MINEGPT_HOST=your_server_ip_here

# Порт вашего сервера (стандартный - 25565)
MINEGPT_PORT=25565

# Версия Minecraft, на которой работает сервер (например, 1.18.2, 1.20.1)
# ВАЖНО: должна точно совпадать с версией сервера!
MINEGPT_VERSION=1.18.2


# === АУТЕНТИФИКАЦИЯ ===
# Выберите ОДИН из двух вариантов ниже.

# --- ВАРИАНТ А: Для лицензионных серверов (online-mode=true) ---
# Укажите email от вашей учетной записи Microsoft и пароль.
# Бот будет заходить под вашим лицензионным аккаунтом, но никнеймы в игре будут Alice, Bob и т.д.
# MINEGPT_USERNAME=your_microsoft_email@example.com
# MINEGPT_PASSWORD=your_microsoft_password

# --- ВАРИАНТ Б: Для "пиратских" серверов (offline-mode=false) ---
# Оставьте эти поля ЗАКОММЕНТИРОВАННЫМИ или ПУСТЫМИ.
# Боты будут использовать никнеймы Alice, Bob, Charlie, David.
# MINEGPT_USERNAME=
# MINEGPT_PASSWORD=

```

**Как пользоваться шаблоном:**
- **Заполните** обязательные параметры.
- **Выберите** один из вариантов аутентификации, раскомментируйте (уберите `#`) и заполните его, если это необходимо.

## 3. Запуск симуляции

После настройки `.env` файла, запустите проект командой:
```bash
npm start
```
Эта команда запустит **сервер сообщений** и **всех ботов** (Alice, Bob, Charlie, David). В вашем терминале вы увидите все их логи: как они проводят выборы, как Староста ставит задачи, а рабочие их выполняют.

## 4. Остановка симуляции

Чтобы остановить всех ботов и сервер сообщений, просто нажмите `Ctrl+C` в окне терминала.

Приятного наблюдения за вашей новой цивилизацией!

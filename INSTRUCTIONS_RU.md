# Инструкция по запуску проекта "Цивилизация Ботов"

Здравствуйте!

Этот проект содержит полностью реализованную симуляцию "цивилизации" ботов для Minecraft. Боты могут самостоятельно выбирать лидера (Старосту), который, в свою очередь, ставит цели для деревни (например, "добыть 64 блока дерева" или "скрафтить 4 печки"), а боты-рабочие координируются для их выполнения.

**Важное замечание:** Тестовый сервер (`flying-squid`), включенный в этот репозиторий, оказался нестабильным в среде разработки и падает при подключении ботов. Поэтому для запуска симуляции необходимо подключить ботов к **вашему собственному, стабильному серверу Minecraft**.

## Шаги для запуска

### 1. Установка зависимостей

Если вы еще не сделали этого, откройте терминал в папке проекта и выполните команду:
```bash
npm install
```

### 2. Настройка подключения к вашему серверу

Вам нужно создать файл с именем `.env` в корневой папке проекта. Этот файл будет содержать данные для подключения к вашему серверу.

Создайте файл `.env` и добавьте в него следующие строки:

```dotenv
# Адрес вашего сервера Minecraft
MINEGPT_HOST=localhost

# Порт вашего сервера (стандартный порт - 25565)
MINEGPT_PORT=25565

# Версия Minecraft, на которой работает ваш сервер (например, 1.18.2, 1.20.1 и т.д.)
MINEGPT_VERSION=1.18.2

# Пароль от вашей учетной записи Microsoft (ОСТАВЬТЕ ПУСТЫМ ДЛЯ ОФФЛАЙН-СЕРВЕРОВ)
# Если вы укажете здесь пароль, боты будут пытаться войти через Microsoft-аутентификацию.
# Если ваш сервер работает в оффлайн-режиме (cracked), просто оставьте это поле пустым.
MINEGPT_PASSWORD=
```

**Обязательно замените `localhost`, `25565` и `1.18.2` на реальные данные вашего сервера!**

### 3. Запуск симуляции

После того как вы настроили `.env` файл, вы готовы к запуску. Выполните в терминале команду:

```bash
npm start
```

Эта команда запустит всех ботов (Alice, Bob, Charlie, David). Они начнут подключаться к вашему серверу. В вашем терминале вы увидите все их логи: как они проводят выборы, как Староста выбирает место для деревни, ставит задачи, а рабочие их выполняют.

### 4. Остановка симуляции

Чтобы остановить всех ботов, просто нажмите `Ctrl+C` в окне терминала, где вы запускали `npm start`.
